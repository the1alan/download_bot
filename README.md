# 🎵 Telegram Music Bot

Легальный компактный Telegram-бот для поиска и скачивания музыки из публичных источников.

## ✨ Возможности

- 🔍 Поиск музыки по названию или исполнителю
- 📥 Скачивание MP3 высокого качества (192 kbps)
- 📄 Пагинация результатов (по 10 треков)
- ⚡ Быстрая работа с ограничением одновременных загрузок
- 🛡️ Троттлинг для защиты от спама
- 🗑️ Автоматическая очистка временных файлов

## 📋 Требования

- Python 3.11+
- FFmpeg (системная зависимость)
- Telegram Bot Token

## 🚀 Установка

### 1. Установка FFmpeg

**macOS:**
```bash
brew install ffmpeg
```

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**Windows:**
Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте в PATH.

### 2. Клонирование и настройка

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация
# macOS/Linux:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Создание конфигурации
cp .env.example .env
```

### 3. Настройка токена

Отредактируйте `.env` и добавьте токен бота:

```env
BOT_TOKEN=your_bot_token_here
```

Получить токен можно у [@BotFather](https://t.me/BotFather) в Telegram.

## 🎮 Запуск

```bash
python music_bot.py
```

## 📖 Использование

### Команды

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/cancel` - Отменить текущий поиск

### Поиск музыки

Просто отправьте текстовое сообщение с запросом:

```
Imagine Dragons - Believer
```

или

```
lofi hip hop
```

Бот найдет до 30 треков и покажет первые 10 с возможностью пролистывания.

### Скачивание

1. Выберите трек из списка результатов
2. Дождитесь скачивания
3. Получите MP3 файл

## ⚙️ Технические детали

### Архитектура

- **Компактность**: ~400 строк кода в одном файле
- **Асинхронность**: полностью асинхронная работа с aiogram 3
- **Безопасность**: 
  - Троттлинг запросов (2 сек между запросами)
  - Семафор для ограничения загрузок (макс. 3 одновременно)
  - Очистка имен файлов от опасных символов
  - Автоудаление временных файлов

### Источники

- **YouTube**: публичные видео через yt-dlp
- Только контент, доступный для свободного просмотра

### Ограничения

- Максимальный размер файла: 49 МБ
- Максимальная длительность трека: 10 минут
- Качество аудио: MP3 192 kbps
- Троттлинг: 2 секунды между запросами

## 🐛 Решение проблем

### Бот не запускается

Проверьте:
- Установлен ли FFmpeg: `ffmpeg -version`
- Правильно ли указан токен в `.env`
- Установлены ли все зависимости: `pip install -r requirements.txt`

### Ошибка при скачивании

Возможные причины:
- Трек слишком длинный (>10 минут)
- Файл слишком большой (>49 МБ)
- Видео недоступно или удалено
- Проблемы с интернет-соединением

### Бот не отвечает

- Проверьте логи в консоли
- Убедитесь, что бот запущен
- Проверьте интернет-соединение
